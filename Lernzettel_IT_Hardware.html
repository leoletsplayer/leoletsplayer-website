01 Serielle Datenübertragung

Grundlagen, die für UART, SPI und I2C wichtig sind.

Seriell vs. parallel

Bei serieller Übertragung werden Bits nacheinander auf einer Leitung gesendet, bei paralleler gleichzeitig auf mehreren. Seriell hat den Vorteil, dass Laufzeitunterschiede einzelner Leitungen entfallen und damit höhere Taktfrequenzen möglich sind. Heute Standard bei USB, HDMI, SPI, I2C, UART.

Synchron vs. asynchron

  • Synchron: Sender und Empfänger werden über ein zusätzliches Taktsignal synchronisiert (SPI, I2C).
  • Asynchron: Kein gemeinsamer Takt, beide Seiten müssen vorher dieselbe Geschwindigkeit (Baudrate) eingestellt haben (UART).

Betriebsarten

BegriffBedeutungBeispiel
SimplexNur in eine RichtungRadio, TV
HalbduplexBeide Richtungen, aber nicht gleichzeitigAmateurfunk, I2C
VollduplexBeide Richtungen gleichzeitigTelefon, SPI

02 UART

Universal Asynchronous Receiver / Transmitter. Einfaches, asynchrones Punkt-zu-Punkt-Protokoll.

Grundprinzip

UART nutzt nur zwei Leitungen plus GND und arbeitet asynchron, also ohne gemeinsames Taktsignal. Dadurch müssen beide Seiten dieselbe Baudrate eingestellt haben.

Anschlüsse

PinBedeutung
TXTransmitter (Sender)
RXReceiver (Empfänger)
GNDMasse

Verbindung: TX des einen Geräts an RX des anderen (gekreuzt).

Baudrate

Baud ist die Einheit für die Symbolrate. Bei UART codiert ein Symbol genau 1 Bit.

Baudrate = 1 / T     (T = Dauer eines Symbols)

Übliche Baudraten: 4800, 9600, 19200, 57600, 115200.

Rahmenformat (Frame)

Damit der Empfänger den Datenanfang erkennt, werden die Bits in einen Rahmen gepackt:

Start
Datenbits (5–9, typisch 8)
Parität
Stop
  • Startbit: immer 0, signalisiert den Beginn
  • Datenbits: typisch 8 Bit
  • Paritätsbit: optional, zur Fehlererkennung
  • Stoppbit: 1 oder 2 Bit

Einsatzgebiete

Früher: serielle Ports, RS-232, Modems. Heute: einfache, langsame Verbindungen, z. B. zum Bluetooth-Modul HM-10, ST-Link USB-UART-Brücke zum PC, Konfiguration von Routern (Cisco-Befehle).

UART am Nucleo L152RE

  • USART2: PA2 (TX), PA3 (RX) – fest mit ST-Link verbunden
  • USART3: PB10 (TX), PB11 (RX) – z. B. fürs Bluetooth-Modul

HardwareSerial-Befehle

BefehlBedeutung
HardwareSerial SerialPC(RX, TX);Objekt mit Pins erzeugen
SerialPC.begin(9600);Baudrate festlegen
SerialPC.available();true, wenn Daten im Puffer
SerialPC.read();Ein Zeichen aus Puffer lesen
readStringUntil('\n');Puffer bis Zeilenumbruch lesen
SerialPC.println(...);Senden mit Zeilenumbruch

Beispiel: LED über UART steuern

#include <Arduino.h>
HardwareSerial SerialPC(PA3, PA2);

void setup() {
  SerialPC.begin(9600);
  pinMode(PC0, OUTPUT);
}

void loop() {
  if (SerialPC.available()) {
    String s = SerialPC.readStringUntil('\n');
    if (s.equals("LED0_ein")) digitalWrite(PC0, HIGH);
    if (s.equals("LED0_aus")) digitalWrite(PC0, LOW);
  }
}

Vorteile

  • Einfach, nur 2 Drähte
  • Kostengünstig
  • Vollduplex möglich

Nachteile

  • Nur Punkt-zu-Punkt
  • Beide Seiten brauchen dieselbe Baudrate
  • Eher langsam

03 SPI

Serial Peripheral Interface. Synchroner, schneller Bus mit 4 Leitungen, vollduplex.

Grundprinzip

Synchroner, serieller Bus nach Master-Slave-Prinzip (neu: Controller/Target). Vollduplex, also gleichzeitiges Senden und Empfangen über getrennte Leitungen.

Leitungen (4 Stück, alle unidirektional)

LeitungBedeutung
SCLKTaktsignal vom Master
MOSIMaster Out, Slave In
MISOMaster In, Slave Out
SS / CSSlave Select / Chip Select (low-aktiv, eine pro Slave)

Ablauf einer Übertragung

  1. Master zieht CS des gewünschten Slaves auf LOW
  2. Master erzeugt Takt auf SCLK
  3. Mit jedem Taktpuls wird gleichzeitig 1 Bit auf MOSI gesendet und 1 Bit auf MISO empfangen (Schieberegister-Prinzip)
  4. Master zieht CS wieder auf HIGH

Betriebsarten (CPOL / CPHA)

ModeCPOLCPHARuhepegel SCLKEinlesen bei
000Low1. Flanke (steigend)
101Low2. Flanke (fallend)
210High1. Flanke (fallend)
311High2. Flanke (steigend)
  • CPOL = Clock Polarity (Ruhepegel des Takts)
  • CPHA = Clock Phase (welche Flanke abgetastet wird)
Wichtig: Master und Slave müssen denselben Mode benutzen, sonst klappt die Kommunikation nicht.

SPI-Pins am Nucleo L152RE

BusMOSIMISOSCLK
SPI2PB15PB14PB13
SPI1PB5PB4PB3
SPI1 (alt)PA7PA6PA5

Wichtige SPI-Befehle (Arduino)

BefehlBedeutung
#include <SPI.h>Bibliothek einbinden
SPI.setMOSI(PB15);Alternative Pins setzen
SPI.begin();Bus initialisieren
SPI.beginTransaction(SPISettings(...));Übertragung mit Frequenz, Bit-Order, Mode starten
SPI.transfer(byte);1 Byte senden & empfangen
SPI.endTransaction();Übertragung beenden

Beispiel: 8x8 LED-Matrix (MAX7219)

void send_data(unsigned char address, unsigned char data) {
  digitalWrite(CS, LOW);
  SPI.transfer(address);
  SPI.transfer(data);
  digitalWrite(CS, HIGH);
}

Vorteile

  • Schnell (schneller als I2C)
  • Vollduplex
  • Kein Adress-System nötig
  • Kontinuierliches Streamen möglich

Nachteile

  • 4 Leitungen, jeder Slave eigene CS
  • Nur ein Master
  • Keine Empfangsbestätigung (kein ACK)
  • Keine eingebaute Fehlerprüfung

04 I2C

Inter Integrated Circuit. Synchroner 2-Draht-Bus mit Adressierung, halbduplex.

Grundprinzip

Synchroner, serieller 2-Draht-Bus, von Philips 1982 entwickelt. Halbduplex, Master-Slave-Prinzip (neu: Controller/Target). Mehrere Teilnehmer an denselben zwei Leitungen.

Leitungen

LeitungBedeutung
SDASerial Data
SCLSerial Clock
Open Drain: Beide Leitungen brauchen Pull-Up-Widerstände (typisch 4,3 kΩ bis 10 kΩ bei 5 V). Viele Module bringen die Widerstände schon mit.

Eigenschaften

  • Reichweite: typischerweise nur Platinengröße (ca. 50 cm)
  • Standard Mode: 100 kbit/s
  • Fast Mode: 400 kbit/s
  • Fast Mode Plus: 1 Mbit/s
  • High Speed: 3,4 Mbit/s

Adressierung

Jeder Slave hat eine 7-Bit-Adresse. Die oberen 4 Bit sind oft vom Hersteller fest, die unteren 3 Bit am Baustein einstellbar (Pins A0–A2). Damit lassen sich z. B. bis zu 8 PCF8574 am selben Bus betreiben.

BitA6A5A4A3A2A1A0R/W
Inhaltherstellerfesteinstellbar0=W, 1=R

Frame-Aufbau

  1. START (Master zieht SDA auf LOW während SCL HIGH)
  2. Adresse + R/W-Bit (7+1 Bit)
  3. ACK vom Slave (0 = OK)
  4. Datenbytes mit jeweils ACK
  5. STOP (SDA von LOW auf HIGH während SCL HIGH)

I2C-Pins am Nucleo L152RE

BusSDASCL
I2C1PB9PB8
I2C1 (alt)PB7PB6
I2C2PB11PB10

Wire-Library Befehle

BefehlBedeutung
Wire.begin();Bus initialisieren (Master)
Wire.beginTransmission(addr);Übertragung an Slave starten
Wire.write(byte);Byte in Sendepuffer schreiben
Wire.endTransmission();Sendepuffer übertragen, STOP senden
Wire.requestFrom(addr, n);n Bytes von Slave anfordern
Wire.read();Byte aus Empfangspuffer lesen
Hinweis: Wire.write() schreibt nur in den Puffer. Erst endTransmission() sendet wirklich.

Beispiel: Schreiben und Lesen

// Schreiben
Wire.beginTransmission(SENSOR_ADDRESS);
Wire.write(0x9f);
Wire.endTransmission();

// Lesen
Wire.requestFrom(SENSOR_ADDRESS, 2);
unsigned char b1 = Wire.read();
unsigned char b2 = Wire.read();

Vorteile

  • Nur 2 Leitungen
  • Mehrere Slaves an einem Bus
  • Adressierung statt CS-Pins
  • ACK zur Bestätigung

Nachteile

  • Pull-Ups nötig
  • Begrenzte Reichweite
  • Nur Halbduplex
  • Adressen oft mehrfach vergeben

06 Analoger Eingang (ADC)

Wandelt analoge Spannungen in digitale Werte um. Gegenstück: DAC.

Vor- und Nachteile

VorteileNachteile
AnalogStufenlos, beliebig viele ZwischenwerteStöranfällig, Verzerrungen, Ablesefehler
DigitalStörsicher, einfach speicherbar, flexibelEndlich viele Zustände, Informationsverlust

Funktionsprinzip

  1. Abtastung: in regelmäßigen Abständen wird die Spannung gemessen
  2. Digitalisierung: der Spannung wird ein digitaler Wert zugeordnet

Shannon-Abtasttheorem

Die Abtastfrequenz muss mehr als doppelt so hoch wie die höchste im Signal vorkommende Frequenz sein:

f_abtast > 2 · f_max

Sonst kann das Signal nicht korrekt rekonstruiert werden.

Auflösung

  • 8-Bit-ADC: 2⁸ = 256 Stufen
  • 12-Bit-ADC (STM32): 2¹² = 4096 Stufen
ΔU = U_ref / 2ⁿ
Beispiel: 12-Bit-ADC mit U_ref = 3,3 V (Nucleo)
ΔU = 3,3 V / 4096 ≈ 0,806 mV

Wägeverfahren (sukzessive Approximation)

Verfahren des STM32-ADC: ein internes Register (SAR) wird Bit für Bit gefüllt, beginnend mit dem MSB. Mit einem internen DAC und Komparator wird geprüft, ob das Bit gesetzt bleibt. Bei jedem Takt wird ein Bit angenähert.

ADC am STM32L152RE

  • 12 Bit, sukzessive Approximation
  • bis zu 42 Kanäle
  • Wandlungszeit 1 µs (max. Speed) bis 4 µs (low Speed)
  • Referenzspannung: 3,3 V

Analog-fähige Pins: PA0–PA7, PB0, PB1, PB12–PB15, PC0–PC5

Programmierung

BefehlBedeutung
analogReadResolution(12);Auflösung auf 12 Bit setzen
int wert = analogRead(PA0);Spannung an Pin einlesen

Beispiel: Potentiometer einlesen

#define POTI PA0
#define U_MAX 3.3
#define ADC_MAX 4095

void setup() {
  analogReadResolution(12);
}

void loop() {
  int adc_wert = analogRead(POTI);
  float U = adc_wert * U_MAX / ADC_MAX;
}
Hinweis: Vor Float-Berechnung mit Integern besser explizit casten:
float adc_norm = (float) adc_wert / 4095;

07 PWM

Pulsweitenmodulation. Pseudo-analoge Ausgabe mit nur einem digitalen Pin.

Grundidee

Bei PWM wird ein digitales Signal (HIGH/LOW) so schnell ein- und ausgeschaltet, dass im zeitlichen Mittel eine bestimmte Leistung am Verbraucher ankommt. Damit lassen sich z. B. LEDs dimmen oder Motoren in der Drehzahl regeln, ohne einen DAC.

Wichtige Begriffe

BegriffBedeutung
Periodendauer TDauer einer kompletten Schwingung
Frequenz ff = 1 / T
Tastgrad (Duty Cycle)Verhältnis Einschaltzeit zu Periodendauer

Tastgrad

Tastgrad = t_HIGH / T
  • 0 % → dauerhaft LOW (LED aus)
  • 50 % → halbe Helligkeit
  • 100 % → dauerhaft HIGH (LED maximal hell)

Frequenzwahl

  • LEDs: ab ca. 200 Hz flimmerfrei
  • Motoren: typisch im kHz-Bereich

Programmierung am Nucleo

BefehlBedeutung
analogWrite(pin, wert);PWM ausgeben (Default 8 Bit, 0–255)
analogWriteResolution(bit);Auflösung ändern
analogWriteFrequency(hz);PWM-Frequenz setzen

Beispiel: LED dimmen mit Potentiometer

#define POTI PA0
#define LED  PC6

void setup() {
  analogReadResolution(8);          // 0..255
  analogWriteFrequency(200);        // 200 Hz, kein Flackern
  pinMode(LED, OUTPUT);
}

void loop() {
  int wert = analogRead(POTI);      // 0..255
  analogWrite(LED, wert);           // direkt als Tastgrad
  delay(500);
}

Vorteile

  • Einfacher als ein DAC
  • Sehr effizient (kaum Verlustleistung)
  • Universell: LEDs, Motoren, Servos, Audio

Nachteile

  • Frequenz muss richtig gewählt werden
  • Kein echtes Analogsignal
  • Kann hörbares Pfeifen erzeugen

08 Merksätze für die Prüfung

  • UART = asynchron, 2 Leitungen, Punkt-zu-Punkt, Baudrate vorher festlegen
  • SPI = synchron, 4 Leitungen, schnell, Vollduplex, ein CS pro Slave
  • I2C = synchron, 2 Leitungen, Halbduplex, 7-Bit-Adressen, Pull-Ups nötig
  • ADC: ΔU = U_ref / 2ⁿ  ·  Shannon: f_abtast > 2 · f_max
  • PWM: digitaler Pin + Tastgrad → Pseudo-analoge Ausgabe, Frequenz hoch genug wählen
